Fishing and Hunting Predictor

Best times to hunt and fish for a location — a few labelled slots, one reason each.

Settings — optional API keys (stored only on this device)

No key is built into this app or its repository. USGS/NCEI calls are not used in v1; these fields are for future use with your own keys.

Scoring follows the evidence: dawn/dusk, season, temperature and moving water carry the score. Solunar is a tie-breaker only in saltwater; moon phase and solar activity score zero.
